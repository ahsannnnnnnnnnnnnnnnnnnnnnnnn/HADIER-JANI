HAIDER JANI — PORTFOLIO WEBSITE

Files:
- index.html: page content
- style.css: responsive styling and animations
- script.js: mobile navigation and scroll reveal animations

CUSTOMIZE BEFORE PUBLISHING:
1. Open index.html in a text editor.
2. Replace your-email@example.com with your actual email address (search for it twice).
3. Update the BBA education section with your institution and dates.
4. Replace the sample project cards with real projects when available.
5. Do not claim the sample project concepts as client work or real results.

RUN LOCALLY:
Double-click index.html to preview it in your browser.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in at https://github.com/
2. Create a new PUBLIC repository named haider-jani-portfolio.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. Your live URL should look like:
   https://YOUR-USERNAME.github.io/haider-jani-portfolio/
   Replace YOUR-USERNAME with your GitHub username.

This is a static site: no paid hosting or backend is required. A live public link requires completing the GitHub Pages publishing steps in your own account.
